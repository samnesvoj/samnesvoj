# О Соне

Занимаюсь разработкой программного обеспечения, backend, веб-приложениями, искусственным интеллектом и автоматизацией.

Работаю над проектами целиком. Проектирую API, пишу серверную часть, работаю с базами данных, разрабатываю
интерфейсы, подключаю сторонние сервисы и занимаюсь развёртыванием.

Мой основной проект **SONYA** ([sonya.group](https://sonya.group/)). Это собственная платформа для автоматической
обработки видео с использованием компьютерного зрения, распознавания речи, LLM и GPU-вычислений. Помимо неё,
разрабатываю Telegram-приложения, сайты, инструменты автоматизации и приложения для разных платформ.

Делаю сайты и веб-приложения на React, JavaScript, HTML и CSS. Разрабатываю и интегрирую AI-чаты на сайты, подключаю
языковые модели и настраиваю взаимодействие с внешними сервисами.

Отдельное направление моей работы связано с разработкой пайплайнов на заказ. Создаю автоматизированные процессы для
обработки данных, генерации контента, публикаций, интеграции API и взаимодействия между различными сервисами.
Использую Python, n8n, JavaScript и другие инструменты в зависимости от задачи.

Также разрабатываю Google Формы программно через Google Apps Script. Могу автоматизировать их создание, настроить
обработку ответов, подключение Google Таблиц и выполнение различных действий после отправки формы.

Работаю с Yandex Cloud и Timeweb Cloud, являюсь партнёром Timeweb Cloud. Есть опыт интеграции Robokassa, YooKassa и
Самозанятые.рф.

Учусь на первом курсе Кубанского государственного аграрного университета (КубГАУ) по направлению «Прикладная
информатика». Прохожу C++ Middle в Яндекс Практикуме: современный C++, управление памятью, шаблоны,
метапрограммирование и инструменты разработки. Интересуюсь системным программированием, HPC, low latency и устройством
высокопроизводительных систем.

Работаю как самозанятая. Принимаю заказы на разработку и рассматриваю предложения о сотрудничестве, коммерческих
проектах и работе.
