# About Sonya

I work on software development, backend, web applications, artificial intelligence and automation.

I work on projects end to end. I design APIs, write the server side, work with databases, build interfaces,
connect third-party services and handle deployment.

My main project is **SONYA** ([sonya.group](https://sonya.group/)) — my own platform for automated video processing
using computer vision, speech recognition, LLMs and GPU computing. Beyond it, I build Telegram applications,
websites, automation tools and apps for different platforms.

I build websites and web applications with React, JavaScript, HTML and CSS, and I develop and integrate AI chats
into websites — connecting language models and external services.

A separate part of my work is building custom pipelines to order: automated processes for data processing,
content generation, publishing, API integration and communication between services, using Python, n8n,
JavaScript and other tools depending on the task.

I also build Google Forms programmatically with Google Apps Script: I can automate their creation, set up response
handling, connect Google Sheets and trigger actions after a form is submitted.

I work with Yandex Cloud and Timeweb Cloud and am a Timeweb Cloud partner. I have experience integrating Robokassa,
YooKassa and Samozanyatye.rf.

I'm a first-year Applied Informatics student at Kuban State Agrarian University (KubSAU) and I'm taking the
C++ Middle course at Yandex Practicum — modern C++, memory management, templates, metaprogramming and development
tools. I'm interested in systems programming, HPC, low latency and how high-performance systems are built.

I work as a self-employed developer, take on development orders and am open to collaboration, commercial projects
and job offers.
